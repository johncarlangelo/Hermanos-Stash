# Hermanos Stash

A local-first desktop toolbox for files, documents, media, text, developer utilities, and whatever useful tools get added next.

## Project philosophy

Stash is not trying to be a website containing 200 tiny pages.

It is a cohesive utility workstation:

> Find a tool → do the work → get the result.

## Current direction

- Electron
- React
- TypeScript
- Vite
- Tailwind CSS + CSS Modules + design tokens
- SQLite
- Local processing
- Modular tool registry
- Dark-only premium UI
