# Awesome DESIGN.md - Curated Design System Collection

A curated library of **73+ real-world DESIGN.md specifications** extracted from leading technology websites and products. Use this skill when you want to model a UI design or component system after an established design language.

## How to Use

When building UI, pages, or components, you can reference the `design-md/<company>/DESIGN.md` file corresponding to the aesthetic you want to replicate.

Each `DESIGN.md` defines:
1. **Visual Theme & Atmosphere** — Mood, density, design philosophy
2. **Color Palette & Roles** — Semantic token names, hex codes, and background/surface roles
3. **Typography Rules** — Display and body font families, font weights, size scales, and hierarchy
4. **Component Stylings** — Buttons, cards, inputs, navigation, tags, and active/hover states
5. **Layout Principles** — Spacing scales, container widths, grid rules, and whitespace
6. **Depth & Elevation** — Shadow systems, border treatments, blur effects, surface hierarchy
7. **Do's and Don'ts** — Strict guardrails, anti-patterns to avoid
8. **Responsive Behavior** — Breakpoints, touch targets, collapsible layouts
9. **Agent Prompt Guide** — Quick color reference and generation prompts
